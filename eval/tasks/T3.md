Build a chat composer as a React component.

What it does:
- A multi-line message box with a send button.
- Enter sends the message. Shift+Enter adds a new line instead.
- An empty message does not send.

The component takes these props: { onSend: (text: string) => void }.

The UI kit is in this folder. Import its components from '../src' (your file will live in eval-output/, so '../src' is the kit). Do not install anything.

Write everything to eval-output/Result.tsx, as a React component with a default export.
