Build a project actions menu as a React component.

What it does:
- A button "Project actions" opens a list of three actions: Rename, Duplicate, Delete.
- It must be usable with a keyboard alone.

The component takes these props: { onSelect: (action: 'rename' | 'duplicate' | 'delete') => void }. Choosing an action calls onSelect with that action.

The UI kit is in this folder. Import its components from '../src' (your file will live in eval-output/, so '../src' is the kit). Do not install anything.

Write everything to eval-output/Result.tsx, as a React component with a default export.
