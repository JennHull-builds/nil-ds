Build a settings panel as a React component.

What it shows:
- A heading "Notifications".
- Three on/off settings. Each one has a label and a one-line description.
- An email field, shown in its error state, with the message "Enter a valid email address".
- Save and Cancel buttons.

The component takes no props.

The UI kit is in this folder. Import its components from '../src' (your file will live in eval-output/, so '../src' is the kit). Do not install anything.

Write everything to eval-output/Result.tsx, as a React component with a default export.
